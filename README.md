# Axle Energy

Axle Energy runs a virtual power plant (VPP) platform that connects distributed energy assets — EVs, EV chargers, home batteries, and heat pumps — to electricity flexibility markets through a single unified API. Partners register sites and assets, prequalify and enrol them in flex propositions, stream telemetry and events, and let end users monetise shiftable demand across GB, France, Germany, the Netherlands, Denmark and Sweden.

- Website: https://www.axle.energy/
- Developer docs: https://docs.axle.energy/introduction
- API reference: https://docs.axle.energy/api-reference
